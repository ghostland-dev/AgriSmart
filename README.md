# AgriSmart

Smart agriculture platform for farm management and crop monitoring.

## Features

- Crop, task and supplier management
- Weather, analytics and reports
- Traceability module
- AI advisor page and full auth flow

## Tech Stack

- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/agri-smart.git
cd agri-smart
npm install
```
